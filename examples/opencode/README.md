# OpenCode primary-agent examples

The files under `agents/` are inert examples for the three numbered Concord
coordinator postures. Concord does not install, update, migrate, remove, or
package these files.

A host can copy and adapt an example into its own OpenCode configuration. Keep
the host's model selection, credentials, research-provider grants, and
permission overrides in host-owned configuration.

The examples defer evidence and communication conduct to the installed Concord
conduct corpus. They show coordinator authority and pacing, not a complete host
configuration.
