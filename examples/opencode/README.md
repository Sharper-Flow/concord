# OpenCode intake-agent example

The file under `agents/` is an inert intake example. Concord does not install,
update, migrate, remove, or package it. The generated `Concord` profile under
`.opencode/agents/` owns work-item coordination and ships through the installer.

A host can copy and adapt the intake example into its own OpenCode configuration.
Keep the host's model selection, credentials, research-provider grants, and
permission overrides in host-owned configuration.

The example defers evidence and communication conduct to the installed Concord
conduct corpus. It shows intake authority, not a complete host configuration.
