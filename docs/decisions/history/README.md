# Decision history

Superseded private pre-public decision records remain private and are not part of
this repository. This directory is intentionally empty in the constitutional
snapshot; it is not a placeholder for imported private history.

CD-0002 is the first public retained authority decision. Active public decisions
live in [`../`](../); later superseded public records may be retained here only when
their public content is safe to publish and the active decision names the
supersession.
